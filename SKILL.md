# Winter clothes swap

A playful Egyptian-Arabic checklist page that gets someone started on swapping winter and summer clothes. The page is in `template.html` next to this file.

## Steps

1. Get the person's name. If you already know it, use it. Otherwise ask once, in one short casual line, and wait for the answer. If they don't give one, the page uses "بطل" by itself.
2. Read `template.html` and replace the single `NAME_PLACEHOLDER` in its script with the name, exactly as given. Don't change anything else.
3. Show the finished page: publish it as an HTML artifact if an Artifact tool is available, otherwise render it inline, otherwise send it as an `.html` file.
